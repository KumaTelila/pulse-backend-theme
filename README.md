# Pulse Backend Theme (Community Version)

![Pulse Banner](static/description/Overview.png)

Pulse Backend Theme transforms the default Odoo interface into a modern, dashboard-style experience. **Best for SaaS** environments, it provides a high-performance shell with a persistent sidebar and customizable accent colors.

## Features

- 🚀 **Vertical Apps Sidebar**: Persistent navigation for lightning-fast app switching.
- 🎨 **Dynamic App Icons**: Switch between Odoo default and custom modern icon packs.
- 🎨 **Accent Color Customization**: Dynamic theme controls in General Settings.
- 🛠️ **Two-Row Navbar**: Redesigned top bar for better visibility and navigation.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile.
- 🔐 **Branded Auth**: Beautiful custom login and signup pages.

## Installation

1. Clone or download this repository into your Odoo `custom_addons` folder.
2. Update the Odoo Apps list.
3. Search for **Pulse Backend Theme** and click **Activate**.
4. Go to **Settings → General Settings → Theme Settings** to customize your colors.
